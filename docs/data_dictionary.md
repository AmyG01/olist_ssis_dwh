# Data Dictionary: Olist Data Warehouse

This document describes every table and column in the **Gold** layer (the star schema) and the
**etl** schema (run logging). Bronze and Silver tables mirror the source CSV files; see
[`data_lineage.md`](data_lineage.md) for how data moves between layers.

**Conventions**
- Names are lowercase snake_case.
- `PK` = primary key, `FK` = foreign key, `BK` = business (natural) key from the source data.
- Every dimension contains an **Unknown member** with key `-1`. Fact rows whose lookup fails point to it, so no fact row is ever lost.
- Surrogate keys (`*_key`) are generated by the warehouse and have no business meaning.

## 2. Fact tables

### gold.fact_sales

| Column | Type | Null | Key | Description |
|---|---|---|---|---|
| sales_key | bigint | No | PK | Surrogate key of the sales row |
| order_id | nvarchar(50) | No | BK | Order identifier from the source |
| order_item_id | int | No | BK | Position of the item within the order (1, 2, 3, ...) |
| date_key | int | No | FK | Order purchase date (dim_date) |
| customer_key | int | No | FK | Customer version valid on the purchase date (dim_customer) |
| product_key | int | No | FK | Product sold (dim_product) |

| order_status_key | int | No | FK | Status of the order (dim_order_status) |

| days_to_deliver | int | Yes | | Days from purchase to delivery; NULL if not delivered |
| delivery_delay_days | int | Yes | | Days between the estimated and the actual delivery date; positive means late; NULL if not delivered |
| is_late | bit | Yes | | 1 if delivered after the estimated date, 0 if on time, NULL if not delivered |

## 3. Dimension tables

### gold.dim_customer (SCD Type 2)

A customer who moves city or state gets a new row; the old row is closed by setting `valid_to`.

| Column | Type | Null | Key | Description |
|---|---|---|---|---|
| customer_key | int | No | PK | Surrogate key of this customer version |
| customer_unique_id | nvarchar(50) | No | BK | The real customer identifier (the source `customer_id` changes with every order, so it is not used) |
| geography_key | int | No | FK | Customer's location (dim_geography) |
| city | nvarchar(100) | Yes | | City of the customer in this version |
| state | char(2) | Yes | | Brazilian state code in this version |
| valid_from | date | No | | First date this version applies |
| valid_to | date | No | | Last date this version applies (open-ended for the current version) |
| is_current | bit | No | | 1 for the latest version of the customer, 0 for older versions |

## 4. etl schema (run logging)

### etl.batch_log: one row per run of the master package

| Column | Type | Null | Key | Description |
|---|---|---|---|---|
| batch_id | int | No | PK | Batch number, created when the master package starts |
| start_ts | datetime2 | No | | When the run started |
| end_ts | datetime2 | Yes | | When the run ended; NULL while it is still running |
| status | nvarchar(20) | No | | RUNNING, SUCCEEDED or FAILED |

### etl.load_log: one row per table loaded in a batch

| Column | Type | Null | Key | Description |
|---|---|---|---|---|
| load_id | int | No | PK | Row identifier |
| batch_id | int | No | FK | The batch this load belongs to (etl.batch_log) |
| package | nvarchar(100) | No | | SSIS package that did the load |
| table_name | nvarchar(128) | No | | Table that was loaded |
| rows_read | int | Yes | | Rows read from the source |
| rows_written | int | Yes | | Rows written to the table |
| rows_error | int | Yes | | Rows rejected |
| ts | datetime2 | No | | When the row was logged |

### etl.error_rows: rows rejected by the pipeline

| Column | Type | Null | Key | Description |
|---|---|---|---|---|
| error_id | int | No | PK | Row identifier |
| batch_id | int | No | FK | The batch in which the error happened |
| table_name | nvarchar(128) | No | | Table being loaded when the error happened (`pipeline` for a package-level failure) |
| error_code | int | Yes | | SSIS error code (-1 for a general failure) |
| error_column | nvarchar(100) | Yes | | Column that caused the error (or the package name) |
| raw_row | nvarchar(max) | Yes | | The rejected row, or a message |
| ts | datetime2 | No | | When the error was logged |
